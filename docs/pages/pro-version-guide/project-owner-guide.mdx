# Project Owner Role in CelerBuild

As a Project Owner in CelerBuild, you have comprehensive project management rights within your project. This guide focuses on your key responsibilities in managing project settings, deployments, and team members.

## Primary Permissions

* View project details
* Edit project settings
* Review and approve deployment requests
* Manage project members and their roles


## Managing Project Settings

As a Project Owner, you can:
1. Edit project configurations
2. Update deployment settings
3. Modify build and deployment commands
4. Configure branch/tag settings

## Reviewing Deployments

One of your key responsibilities is managing the deployment process:

1. Review deployment requests from team members
2. Approve or reject deployment applications
3. Monitor deployment status
4. Ensure deployment security and stability

## Managing Project Members

You have full control over project member management:

1. View current project members
2. Add new members to the project
3. Adjust member roles and permissions
4. Remove members when necessary

### How to Manage Members:

![project-owner-members-1](https://github.com/user-attachments/assets/28029df5-8c16-4abb-b190-7810e9d9846c)

1. Navigate to the Members section
2. Click on "Members"
3. To add a new member:
    - Click "Import Members"
    - Search for the user by name or email
    - Select their role (Developer, Reporter, etc.)
    - Click "Import" to confirm

![project-owner-members-2](https://github.com/user-attachments/assets/ce8e3086-ef93-45e5-bbbb-a32bd2e45da1)

> **Note**: For project operations like deletion, copying, or YAML export, please contact your Space Owner as these actions require space-level permissions.

## Best Practices

- Regularly review member roles and permissions
- Maintain clear deployment approval processes
- Document project-specific requirements
- Ensure team members understand their roles
- Keep project settings up-to-date
