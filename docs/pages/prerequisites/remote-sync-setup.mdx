# Remote Sync Setup
import { Callout } from 'nextra-theme-docs'

Remote Sync is a feature that automatically maintains your CelerBuild activation status. When enabled, it eliminates the need for manual reactivation after your license expires.

## Prerequisites

Before proceeding, ensure you have:
    - Download the CelerBuild binary (see [Download](./download))
    - Database configured (see [Database Configuration](./database-configuration))

## Accessing the CelerBuild Dashboard

1. Open a web browser and navigate to:
```shell copy
http://localhost:8666/login
```
<Callout type="info">
    If you've configured a different port, use that instead of 8666.
</Callout>

2. Log in with the default credentials:
```
Username: admin
Password: admin@12345
```

<Callout type="warning">
    For security reasons, please change your password immediately after first login. You can change your password in Settings/Profile.
</Callout>

## Changing the Default Password

1. After logging in, go to User Settings
2. Locate the password change section
3. Enter your new password and confirm it
4. Save your changes

## Enabling Remote Sync

1. In the CelerBuild dashboard, navigate to Settings > Subscription
2. Find the "Remote Sync" option
3. Toggle the switch to enable Remote Sync

## Configuring Access Keys

1. Visit the [CelerBuild Account Page](https://celerbuild.com/account)
2. Locate your Access Keys in the account dashboard
3. Copy your Access Keys
4. Return to the CelerBuild dashboard
5. In the Remote Sync settings, paste your Access Keys
6. Save your changes

## Verifying Remote Sync

After configuring Remote Sync:

1. Check the Remote Sync status in the dashboard
2. Ensure it shows as "Connected" or "Active"
