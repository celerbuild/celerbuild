# Space Management
import { Callout } from 'nextra-theme-docs'

<Callout type="info">
    Space management is a Pro Version feature. It allows for advanced organizational control and resource allocation.
</Callout>

This guide explains how to manage spaces in CelerBuild Pro. Only administrators and designated space owners have access to these functions.

## Overview

Spaces are top-level organizational units that help manage projects and resources efficiently. They allow you to:
- Group related projects
- Manage access and permissions
- Allocate resources

## Creating a Space

To create a new space:

1. Navigate to the "Spaces" section in the admin panel
2. Click the "New" button
3. Fill in the required information:
    - Space Name
    - Description

4. Click "Create" to add the space

![admin-create-space](https://github.com/user-attachments/assets/a5bf5a1b-f002-4ca1-bc33-a45013eb2412)

## Editing a Space

To edit an existing space:

1. Select the space from the list
2. Click "Edit" button
3. Modify the space details as needed
4. Click "Save" to apply changes

![admin-edit-space](https://github.com/user-attachments/assets/651e77ba-b865-418d-933f-3001a8eb949c)

## Deleting a Space

To delete a space:

1. Select the space from the list
2. Click "Delete" button
3. Confirm the deletion

![admin-delete-space](https://github.com/user-attachments/assets/fc79f369-f713-4e6e-bb9b-7842f2e75f91)

<Callout type="warning">
    - Spaces that contain projects cannot be deleted. You must first delete or move all projects from the space.
    - Deleting a space is permanent and cannot be undone.
    - Ensure backups are made if necessary before deletion.
</Callout>

## Managing Space Owners

### Adding a Space Owner

1. Click on `Spaces` and select `Members`.
2. Import users and assign the role as `Owner`.
3. Click the `Import` button to add the user as an owner.

![admin-members](https://github.com/user-attachments/assets/f5370258-c21e-45dc-b336-7a53dea8c310)

![admin-import-owner](https://github.com/user-attachments/assets/1ec8a203-9919-4d7a-bcfc-b005236db1f2)

### Managing Space Members

- For members already in the space, you can edit their roles or remove them as needed.

![admin-space-actions](https://github.com/user-attachments/assets/e1a2d00f-7e9b-4e56-bae0-b403400979c1)

### Additional Notes

- It is recommended that space member management be handled by the space owner. The admin's responsibility is primarily to import and assign the space owner.





## Best Practices

- Regularly review space configurations and access permissions
- Use descriptive names and descriptions for spaces
- Document any changes to space settings
