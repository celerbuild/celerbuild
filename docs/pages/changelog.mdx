# Changelog

## [0.8.8] - 2025-03-31

### 🎉 First Release

#### Standard Features
 - Server Clusters: Manage multiple servers as a single deployment unit.
 - Server Management: Centralize server configuration and organization.
 - Environment Management: Efficiently manage various deployment stages.
 - Project Management: Manage unlimited projects with comprehensive configurations.
 - Application Management: Control deployments and rollbacks flexibly.
 - Ticket Management: Track deployment requests and activities.
 - Parallel Multi-server Deployment: Deploy to multiple servers simultaneously with real-time tracking.

#### Pro Features
 - User Management: Centralized control over user accounts with fine-grained access control.
 - Space Management: Create isolated environments for different teams or business units, manage members and permissions, and centralize project and resource management within each space.
 - Space Resources Management: Efficiently manage shared resources within a space for seamless collaboration.
 - Project Member Management: Precise control over roles and access within projects.
 - Ticket Review & Cancel: Project owners and masters have the authority to review deployment tickets, ensuring enhanced security and quality control.
 - Activity Notifications: Stay informed about key activities and changes across your projects and spaces.
 - Comprehensive Audit Logs: Monitor and review all activities across your deployment platform with detailed audit logs.
 - Detailed Operation Logs: Track and monitor all deployment activities with comprehensive logging.

#### System Requirements
- Hardware
    - CPU: 1 core (2+ cores for parallel deployments)
    - RAM: 1GB (2GB+ recommended)
    - Storage: 10GB available space
- Software
    - Git: 2.25.0 or higher
    - MariaDB database
    - SSH access to deployment targets

#### Supported Platforms
- Linux (Ubuntu 20.04+, CentOS 7+, Debian 10+)
- macOS
