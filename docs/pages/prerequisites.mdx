# Prerequisites

Before you start using CelerBuild, you need to complete the following prerequisites.

<Steps>

    ### Install Dependencies

    CelerBuild supports deployment on Linux and macOS environments. Windows deployment is not supported.

    The main dependencies include:
    - MariaDB database
    - SSH public key configuration

    [Learn more about dependencies →](./prerequisites/dependencies)

    ### Download and Install

    Download and install the CelerBuild binary:
    - Get the latest version
    - Set permissions
    - Configure system service

    [Download and install guide →](./prerequisites/download)

    ### Activate CelerBuild

    Activate your CelerBuild installation:
    - Get activation key
    - Complete activation process
    - Verify installation

    [Activation instructions →](./prerequisites/activation)

    ### Configure Database

    Set up the database connection:
    - MariaDB configuration
    - Connection settings
    - Database initialization

    [Database configuration guide →](./prerequisites/database-configuration)

    ### Setup Remote Sync

    Configure remote synchronization:
    - SSH key setup
    - Remote server configuration
    - Connection verification

    [Remote sync setup guide →](./prerequisites/remote-sync-setup)

</Steps>
